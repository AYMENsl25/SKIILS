# SKIILS

Personal skills for Codex and other compatible agents.

- `codex-skills/`: 54 personal Codex skills. Copy the individual skill folders into `%USERPROFILE%\.codex\skills\` on Windows.
- `agent-skills/`: 9 agent skills. Copy the individual skill folders into `%USERPROFILE%\.agents\skills\` if your agent setup uses that directory.

Each skill is a folder with a `SKILL.md` entrypoint. Open a new chat after copying skills so the app can discover them. Review skills and any included scripts before using them on a new computer.

This repository does not contain project folders, chat transcripts, credentials, or plugin-managed skills. Reinstall plugins in the app and transfer project files separately. To recover old Codex chats from another computer, use the same ChatGPT account and workspace, then connect to the old computer through the desktop app's Remote connection feature if it is still available. See the [official Remote connections guide](https://learn.chatgpt.com/docs/remote-connections).
