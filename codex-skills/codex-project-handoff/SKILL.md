# Codex project handoff

First identify the account, workspace, and whether the user means ChatGPT chats, Codex chats, local project folders, cloud tasks, or installed skills. Check current official product guidance before asserting what syncs.

Inventory project names and local paths without exposing private content. For each local folder, identify whether it is Git-backed and whether uncommitted or ignored files matter. Preserve original folders and exports; make an explicit transfer checklist for files that live only on the old computer. Never assume that syncing chats also transfers local files or personal skills.

If the old device is available, prepare a manifest of project folders, remotes, branches, uncommitted changes, skill directories, and required nonsecret configuration. Compare the new device after transfer. Do not copy credentials, private medical data, or sensitive results to a cloud service without specific authorization.

Give recovery steps in order: verify sign-in and workspace, inspect the appropriate app view and archived chats, reconnect or transfer local folders, reinstall personal skills if needed, and escalate to official support only when the expected history remains missing. Clearly mark what was verified on the current device.
